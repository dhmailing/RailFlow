# 사이트 프로필

이 폴더에는 **완성된 프로필이 없습니다.** 일부러 그렇게 뒀습니다.

RailFlow를 만든 개발 환경에서는 공식 예매 사이트로 나가는 연결이 차단돼
있어(자세한 내용: `docs/V0.8-LIVE-BOOKING-AGENT.md` §2) 실제 화면을 볼 수
없었습니다. 화면을 보지 않고 "매진이라는 글자는 아마 이럴 것이다"라고
적어 두면 그건 추측이고, 엉뚱한 열차를 읽을 위험을 만듭니다.

## 프로필은 어떻게 만들어지나

사용자의 PC에서 **RailFlow 로컬 화면**을 통해 만들어집니다.

1. `agent\scripts\2-RailFlow실행.cmd` 실행
2. 열린 화면의 **[공식 화면 열기]**
3. 직접 로그인 → 열차 조회
4. 공식 화면 위 안내를 따라 **열차 행·열차번호·시각·좌석 상태 칸을 클릭**
5. 화면에서 본 상태 문구가 어떤 뜻인지 선택
6. **[자동 검증 시작]** — Agent가 같은 화면을 다시 읽어 확인

전부 통과했을 때만 프로필이 **서명**되어 사용 가능해집니다.

## 저장 위치

```
%USERPROFILE%\.railflow-agent\profiles\<호스트>.profile.json
```

이 저장소가 아니라 사용자의 PC에만 저장됩니다. 파일 이름은 실제로 접속한
호스트에서 만들어집니다 — 사업자 이름을 미리 정해 두지 않습니다.

## 손으로 고칠 수 없습니다

프로필에는 이 PC에만 있는 키로 만든 서명이 들어갑니다. 파일을 편집하면
서명이 깨져 `PROFILE_TAMPERED` 로 거부됩니다. 예전처럼 `"verified": true`
를 직접 켜는 방법은 **존재하지 않습니다.**

고칠 일이 있으면 편집하지 마시고 **[공식 화면 열기]** 를 다시 진행하세요.

## 저장되는 것 / 저장되지 않는 것

**저장됩니다**: 접속한 호스트, 방문한 주소, 화면 구조상의 위치(행 기준
상대 경로와 칸 번호), 조회 폼 라벨, 짧은 상태 문구, 화면 구조 지문.

**저장되지 않습니다**: DOM/HTML 원문, 쿠키, 세션, 토큰, 이름, 회원번호,
전화번호, 이메일, 예약번호, 결제정보.

자세한 절차: [Windows 실행 방법](../README-WINDOWS.md) 3단계
