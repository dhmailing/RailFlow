# RailFlow 실제 연동 — Windows 실행 방법

실제 좌석 상태 조회는 이 프로그램이 합니다. 웹 화면은 안내만 합니다.

> **지금 단계에서는 예약을 하지 않습니다.** 실제 좌석 상태를 읽어서
> 보여주기만 합니다. 예약 버튼은 누르지 않습니다.
>
> 로그인은 **직접** 하십니다. 아이디·비밀번호·OTP를 묻지도, 저장하지도
> 않습니다. 결제정보도 받지 않습니다.

---

## 준비물

- Windows PC
- **Node.js LTS** — https://nodejs.org 에서 "LTS" 버튼으로 설치
  (설치 중 선택지는 기본값 그대로 두시면 됩니다)
- 공식 예매 사이트 **본인 계정**

---

## 눌러야 할 파일 (순서대로)

```
agent\scripts\1-설치.cmd          ← 처음 한 번만
agent\scripts\2-RailFlow실행.cmd  ← 쓸 때마다
agent\scripts\RailFlow종료.cmd    ← 끝낼 때
```

JSON 파일을 열거나 명령어를 입력하실 일은 없습니다.

---

## 1단계 — 설치 (처음 한 번만)

`agent\scripts\1-설치.cmd` 를 **더블클릭**하세요.

검은 창이 열리고 몇 분 동안 필요한 파일을 내려받습니다. "설치가 끝났습니다"
가 보이면 아무 키나 눌러 닫으시면 됩니다.

**Node.js 가 없다는 안내가 나오면**: 창에 적힌 대로 https://nodejs.org 에서
LTS 를 설치하고, **PC를 다시 시작한 뒤** 1단계를 다시 하세요.

---

## 2단계 — 실행

`agent\scripts\2-RailFlow실행.cmd` 를 더블클릭하세요.

1. 검은 창이 열립니다. **이 창은 닫지 마세요.** 닫으면 조회가 멈춥니다.
2. 잠시 뒤 인터넷 브라우저가 자동으로 열리고 RailFlow 화면이 나옵니다.
   (열리지 않으면 검은 창에 적힌 주소 `http://127.0.0.1:4319/` 를 직접
   입력하세요.)

---

## 3단계 — 공식 화면 연결 (처음 한 번만)

RailFlow는 공식 예매 화면의 생김새를 **미리 알고 있지 않습니다.**
"매진"이 어떤 글자로 표시되는지, 열차번호가 어느 칸에 있는지를 추측하면
엉뚱한 열차를 읽을 수 있기 때문입니다. 그래서 **화면을 직접 보여 주시면**
RailFlow가 그 자리를 기억합니다.

1. RailFlow 화면의 **1. 공식 화면 연결** 칸에 공식 예매 화면 주소를
   넣고 **[공식 화면 열기]** 를 누릅니다.
2. 새 브라우저 창이 열립니다. **직접 로그인**하세요.
3. RailFlow 화면에서 **[로그인 완료]** 를 누릅니다.
4. 열린 창에서 **동탄 → 울산(통도사)** 를 조회해 결과 목록을 띄웁니다.
5. RailFlow 화면에서 **[조회 완료]** 를 누릅니다.
6. 이제 공식 화면 위에 주황색 안내 띠가 생깁니다. 안내하는 대로
   **한 번씩 클릭**하시면 됩니다. 마우스를 올리면 테두리가 생겨서
   어디를 누르는지 보입니다.

   | 순서 | 무엇을 누르나 |
   |---|---|
   | 1 | 열차 한 편이 표시된 **줄** 아무 곳 |
   | 2 | 그 줄의 **열차번호** |
   | 3 | **출발시각** |
   | 4 | **도착시각** |
   | 5 | **일반실 상태** (매진/예약가능 같은 글자) |
   | 6 | **특실 상태** (없으면 [특실 없음] 을 누르세요) |
   | 7 | **출발역 입력칸** |
   | 8 | **도착역 입력칸** |
   | 9 | **날짜 입력칸** |
   | 10 | **인원 입력칸** (없으면 건너뛰기) |
   | 11 | **조회 버튼** |

   잘못 누르셨으면 **Esc** 를 누르고 다시 고르시면 됩니다.

7. 공식 화면에서 **예약내역** 화면으로 이동한 뒤, RailFlow 화면에서
   **[예약내역 확인]** 을 누릅니다.
8. RailFlow 화면에 **아까 클릭한 칸에 쓰여 있던 글자들**이 나옵니다.
   각 글자가 어떤 뜻인지 눌러서 골라 주세요. (예: 그 자리에 있던 글자가
   매진을 뜻하면 [매진] 을 누름)
   위쪽의 **사업자 이름** 칸에는 화면에 보이는 회사 이름을 적어 주세요.
9. 공식 화면을 **조회 결과 화면으로 되돌린 뒤**, RailFlow 화면에서
   **[자동 검증 시작]** 을 누릅니다.

RailFlow가 같은 화면을 다시 읽어 지정하신 자리에서 열차번호·시각·좌석
상태가 실제로 나오는지 확인합니다. **전부 확인돼야** 연결이 완료됩니다.
하나라도 어긋나면 무엇이 문제인지 화면에 표시되고, 연결되지 않습니다.

> 이 결과는 이 PC에만 저장됩니다. 화면 원본(HTML), 쿠키, 세션, 이름,
> 전화번호, 예약번호는 저장하지 않습니다.

## 4단계 — 읽기 전용 좌석 조회

RailFlow 화면의 **2. 읽기 전용 좌석 조회** 칸에서:

1. 출발역·도착역·날짜·인원·좌석등급을 확인합니다.
2. 읽고 싶은 **열차번호와 출발시각**을 적습니다 (공식 화면에 보이는 그대로).
3. **[읽기 전용 조회 시작]** 을 누릅니다.
4. 브라우저가 열리면 **직접 로그인**하고, RailFlow 화면에서
   **[로그인 완료]** 를 누릅니다.

그러면 RailFlow가:

1. 그 열차를 한 번 찾고
2. 좌석 상태를 한 번 읽고 (**1회차**)
3. 같은 열차를 한 번 더 읽고 (**2회차**)
4. 두 번이 같은 열차를 읽었는지 확인한 뒤
5. 그때부터 **60초마다** 한 번씩 다시 읽습니다.

화면에는 일반실·특실에 **실제로 쓰여 있던 글자**가 그대로 나옵니다.
좌석 수는 화면에 없으면 만들어내지 않습니다.

---

## 중단하기

- RailFlow 화면의 **[중단]** 버튼 (가장 확실합니다)
- 검은 창에서 **Ctrl+C**
- `agent\scripts\RailFlow종료.cmd`

중단은 60초를 기다리지 않고 바로 먹습니다.

---

## 알아두실 점

- **검은 창을 닫거나 PC가 절전에 들어가면 조회가 멈춥니다.** 화면을 꺼도
  계속 도는 서버 자동조회가 아닙니다.
- 조회는 60초에 한 번입니다. 더 짧게 설정해도 30초 아래로는 내려가지
  않습니다.
- 보안문자·대기열·접근 제한·추가 인증·로그인 만료가 나오면 **즉시
  멈춥니다.** 우회하지 않습니다.
- 공식 화면이 개편되면 **멈춥니다.** 잘못된 칸을 읽는 것보다 멈추는 게
  낫기 때문입니다. 그때는 3단계를 다시 하시면 됩니다.
- **예약·결제는 하지 않습니다.** 이 단계에는 그 기능 자체가 없습니다.

## 문제가 생기면

RailFlow 화면 맨 아래 **3. 진단 요약** 에서 **[진단 요약 만들기]** →
**[복사]** 를 누르면 개인정보 없는 진단 내용이 복사됩니다. 그걸 보내
주시면 됩니다.

| 증상 | 확인할 것 |
|---|---|
| `node` 를 찾지 못한다 | Node.js 설치 후 **PC 재시작** |
| 브라우저가 안 열린다 | 검은 창에 적힌 `http://127.0.0.1:4319/` 를 직접 입력 |
| "이미 실행 중인 Agent" | 열려 있는 다른 검은 창을 먼저 닫기 |
| "프로필이 변경됐습니다" | 3단계(공식 화면 연결)를 다시 진행 |
| "화면 구조가 다릅니다" | 사이트가 개편된 것입니다. 3단계를 다시 진행 |
| 조회가 멈췄다 | 검은 창이 닫혔거나 PC가 절전에 들어갔는지 확인 |

## 로그와 개인정보

```
%USERPROFILE%\.railflow-agent\logs\agent-YYYY-MM-DD.log
```

개인정보가 남지 않았는지 직접 확인하시려면 PowerShell에서:

```powershell
Select-String -Path "$env:USERPROFILE\.railflow-agent\logs\*.log" `
  -Pattern "password|cookie|jsessionid|\d{3}-\d{4}-\d{4}|@"
```

아무 것도 나오지 않아야 합니다. 로그를 지우시려면 `logs` 폴더를
삭제하시면 됩니다.
