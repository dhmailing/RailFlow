# 문의 1 — 코레일(현재 예매 운영 주체)

- 대상: 한국철도공사 고객센터 또는 공공데이터·제휴 담당부서
- 상태: **작성 완료 · 전송하지 않음**
- 작성일: 2026-10-01

---

제목: **승차권 좌석 잔여조회·예약 관련 공식 연동(API) 제공 여부 문의**

안녕하세요.

개인이 만들고 있는 열차 시간표 조회 서비스(비상업·개인 프로젝트)에서, 사용자가 원하는
열차의 **좌석 잔여 상태**를 공식적으로 확인할 수 있는 방법이 있는지 문의드립니다.

현재 저희는 공공데이터포털의 「한국철도공사_열차운행정보」 API를 정식 승인받아 **시간표와
운임 조회에만** 사용하고 있습니다. 해당 API의 응답 항목에는 좌석 관련 정보가 없는 것으로
확인했습니다.

아래 항목에 대해 **가능/불가능 여부만이라도** 알려주시면 감사하겠습니다.

1. **좌석 잔여조회 API** 가 공식적으로 제공되는지 (공개 또는 심사 후 제공 포함)
2. **예약 생성 API** 가 공식적으로 제공되는지
3. **예약내역 재조회 API** 가 공식적으로 제공되는지
4. 위 API가 있다면 **개인 개발자 또는 개인사업자**가 신청할 수 있는지, 아니면 법인·제휴사만
   가능한지
5. 신청 자격이 된다면 **신청 창구와 제출 서류**
6. **테스트 환경(샌드박스)** 이 제공되는지
7. 인증 방식이 **서비스키 / OAuth / 제한된 API credential** 중 무엇인지
8. 서버에서 **제한된 주기로 좌석 상태를 조회**하는 방식이 이용 조건상 허용되는지,
   허용된다면 **허용 주기와 일일 요청 한도**
9. 좌석을 일시 확보한 뒤 **결제는 사용자가 코레일 공식 앱에서 직접 수행**하는 방식(예약 보류)이
   지원되는지
10. 관련 **기술문서·신청서·담당 창구**를 안내받을 수 있는지

참고로 저희가 지키고 있는 원칙을 함께 밝힙니다.

- 공식 예매 화면을 브라우저로 자동 조작하는 방식은 **사용하지 않기로 결정하고 관련 코드를
  제품에서 제거했습니다.**
- 비공개 API를 추측하거나, 앱 통신을 분석하거나, 매크로 탐지·대기열·접근 제한을 우회하는
  방식은 사용하지 않습니다.
- 사용자의 **비밀번호·OTP·쿠키를 입력받거나 저장하지 않습니다.**
- **결제를 자동화하지 않습니다.** 결제는 사용자가 공식 앱에서 직접 합니다.
- 공식·승인된 연동 방법이 확인되지 않으면 **기능을 구현하지 않고 중단합니다.** 현재도
  중단 상태입니다.

**제공되지 않는다면 그 사실만 알려주셔도 충분합니다.** 그 답변을 근거로 이 기능을 접거나,
공식 예약대기 기능을 안내하는 쪽으로 방향을 바꾸겠습니다.

감사합니다.
