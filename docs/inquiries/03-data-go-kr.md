# 문의 3 — 공공데이터포털 담당부서

- 대상: 공공데이터포털(data.go.kr) 운영·활용신청 담당부서
- 상태: **작성 완료 · 전송하지 않음**
- 작성일: 2026-10-01

---

제목: **철도 좌석 잔여조회·예약 관련 공개 API 존재 여부 및 활용신청 가능 여부 문의**

안녕하세요.

현재 「한국철도공사_열차운행정보」 API를 정식 승인받아 운영 환경에서 **시간표·운임 조회**에
사용 중인 개인 개발자입니다(활용기간 2026-09-19 ~ 2028-09-19).

해당 서비스의 응답 항목에 좌석 관련 정보가 없는 것을 확인했습니다. 이에 아래를 문의드립니다.

1. 포털에 등록된 **철도 관련 API 중 좌석 잔여조회를 제공하는 서비스가 있는지**
   (한국철도공사, SR, 국가철도공단, 국토교통부 등 제공기관 무관)
2. **예약 생성 API** 또는 **예약내역 재조회 API** 가 등록된 것이 있는지
3. 있다면 서비스명·제공기관·상세 페이지 주소
4. 그 API가 **개인 개발자**에게도 활용신청이 열려 있는지, 아니면 **심사·자격 제한**이 있는지
5. 포털에 등록되지 않았지만 **제공기관이 별도 절차로 제공하는 철도 좌석·예약 연동**이 있다면,
   어느 기관에 문의해야 하는지
6. 「열차운행정보」 API의 **일일 요청 한도와 운영정책** 원문을 어디서 확인할 수 있는지
7. 공공데이터 **이용 조건상 서버에서 주기적으로 반복 조회**하는 것이 허용되는지, 제한이
   있다면 그 기준

**좌석·예약 API가 등록되어 있지 않다면 그 사실만 알려주셔도 충분합니다.** 포털에 없다는
확인만으로도 저희 판단에 큰 도움이 됩니다.

감사합니다.
