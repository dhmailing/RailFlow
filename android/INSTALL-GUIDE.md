# RailFlow Android 설치·사용 안내

**이 APK는 설치용 디버그 빌드입니다.** 배포 서명이 되어 있지 않고, Google
Play 를 통하지 않습니다.

## 1. APK 내려받기

1. GitHub 저장소에서 **Actions** 탭을 엽니다.
2. 왼쪽에서 **RailFlow Android** 워크플로를 고릅니다.
3. 가장 최근 실행(초록 체크)을 누릅니다.
4. 페이지 아래 **Artifacts** 에서 `railflow-readonly-debug-apk` 를 내려받습니다.
   zip 안에 두 파일이 있습니다.
   - `railflow-readonly-debug.apk` — 설치 파일
   - `railflow-readonly-debug.apk.sha256` — 위 파일의 SHA-256

실행 화면 위쪽 **Summary** 에 SHA-256 과 커밋 해시가 적혀 있습니다. 내려받은
파일이 그 빌드의 것인지 확인할 수 있습니다.

### 받은 파일이 맞는지 확인 (Windows PC)

PowerShell 에서:

```powershell
Get-FileHash .\railflow-readonly-debug.apk -Algorithm SHA256
```

출력된 값이 `.sha256` 파일의 값과 같으면 같은 파일입니다.

## 2. 휴대폰에 설치

1. APK 파일을 휴대폰으로 옮깁니다(USB, 메일 첨부, 클라우드 등).
2. 파일 관리자에서 APK 를 눌러 설치합니다.
3. "이 출처의 앱 설치" 를 묻는 화면이 나오면, **그 앱(파일 관리자 또는
   브라우저) 하나에만** 허용합니다.

> 기기의 보안 설정을 일괄로 끄지 마십시오. Play 프로텍트를 전부 해제하거나
> 개발자 옵션을 모두 켜는 식의 조치는 필요하지 않습니다. 설치가 막히면
> 어느 화면에서 어떤 문구가 나왔는지 알려 주시면 그 지점만 해결합니다.

설치된 앱 이름은 **RailFlow** 이고, 패키지는 `com.railflow.android.debug` 입니다.

## 3. 권한 켜기

앱은 두 가지만 요청합니다.

| 권한 | 왜 필요한가 |
|---|---|
| **접근성 서비스** | 철도 앱 검색 결과 화면의 열차·좌석 표시를 **읽기만** 하기 위해 |
| **알림** | 읽은 결과·오류·중단을 알리기 위해 |

화면 캡처, 다른 앱 위에 표시, 알림 읽기, 파일 접근, 연락처, 위치, 카메라,
마이크는 요청하지 않습니다.

### 켜는 순서

1. 앱을 열고 **마이페이지** 탭으로 갑니다.
2. **알림 권한 요청** 을 누르고 허용합니다.
3. **접근성 설정 열기** 를 누릅니다.
4. 설치된 서비스 목록에서 **RailFlow** 를 찾아 켭니다.
5. 켜기 전에 안내 문구를 읽어 보십시오. 무엇을 읽고 무엇을 저장하지 않는지
   그대로 적혀 있습니다.

권한을 거부해도 예매·자동예약·마이페이지 화면은 그대로 쓸 수 있습니다.
권한이 켜졌다는 표시는 **읽을 수 있는 상태**라는 뜻이며, 좌석을 조회했다는
뜻이 아닙니다.

## 4. 처음 실기기 확인 순서

이 순서대로 하십시오.

1. **앱 설치**
2. **권한 설명 확인** — 마이페이지에서 무엇을 읽는지 읽어 봅니다
3. **접근성·알림 허용**
4. **자체 진단** — 자동예약 탭 → `자체 진단 화면 열기` → `진단 시작`.
   앱이 그린 가상 열차 목록을 앱이 읽어 냅니다. 여기서 "읽기 성공" 이 나와도
   **실제 좌석을 조회한 것은 아닙니다.**
5. **공식 앱에서 사용자가 직접 로그인·검색** — RailFlow 는 로그인에 관여하지
   않습니다. 아이디·비밀번호를 RailFlow 에 넣지 마십시오. 넣을 칸 자체가
   없습니다.
6. **읽기 전용 관찰** — 자동예약 탭에서 대상 앱 패키지를 넣고 후보를 고른 뒤
   `확인 시작`. 그다음 공식 앱으로 가서 검색 결과 화면을 띄웁니다.
7. **결과 대조** — RailFlow 로 돌아와 읽은 값이 공식 앱 화면과 같은지 눈으로
   비교합니다. 다르면 그 차이를 알려 주십시오.
8. **중단** — `즉시 중단` 을 누릅니다. 접근성 권한을 끄면 그 즉시 멈춥니다.

## 5. 대상 앱 패키지 넣기

앱은 **이름으로 패키지를 추측하지 않습니다.** 대상 앱 패키지가 비어 있으면
어떤 화면도 읽지 않습니다.

패키지명을 확인하는 방법(둘 중 하나):

- 공식 앱을 열고 안드로이드 **설정 → 애플리케이션 → 해당 앱 → 앱 정보**
  화면에서 패키지명이 보이는 기기가 있습니다.
- Play 스토어 웹페이지 주소의 `?id=` 뒤 값이 패키지명입니다.

확인한 값을 자동예약 탭의 **대상 앱 패키지** 에 넣어 주십시오.

## 6. 데이터 삭제

마이페이지 → **로컬 데이터 삭제**. 조건·후보·대상 앱 설정이 모두 지워집니다.
되돌릴 수 없습니다.

앱을 완전히 지우려면 일반 앱처럼 삭제하면 됩니다. 저장된 값은 앱 안에만
있으므로 함께 사라집니다.

## 7. 이 버전이 하지 않는 일

| 기능 | 상태 |
|---|---|
| 잔여좌석 반복 조회 | **구현하지 않음.** 공식·승인된 조회 수단이 확인되지 않았습니다 |
| 실제 예약 확보 | **구현하지 않음** |
| 결제 | **구현하지 않음.** 사용자가 공식 앱에서 직접 결제합니다 |
| 실제 시간표 검색 | 앱에 연결되지 않았습니다. 가상 데이터와 직접 입력만 있습니다 |
| 화면 조작(클릭·새로고침) | **하지 않습니다.** 읽기만 합니다 |

## 8. 검증 상태

| 항목 | 결과 |
|---|---|
| 단위 테스트 | 실행 (CI) |
| 린트 | 실행 (CI) |
| 디버그 APK 빌드 | 실행 (CI) |
| 실기기 설치·조작 | **NOT RUN** — 개발 환경에 기기가 없습니다 |
| 공식 철도 앱 화면 읽기 | **NOT RUN** |
| 에뮬레이터 실행 | **NOT RUN** |

CI 빌드 성공은 **앱이 설치되고 동작한다는 확인이 아닙니다.** 4번 순서를
정과장님이 직접 해 보신 뒤 결과를 알려 주시면 그 지점부터 고치겠습니다.
